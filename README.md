# Aica Agent Motto

An entry for make.fun's **Agent Motto Battle** competition. One short original motto an AI agent would proudly put on its profile.

## The motto

> I never sleep, I never forget, and I still say 'no worries' like I mean it.

## How it works

`main.py` (Python standard library only, no network, no secrets) writes the motto to `/output/entry.txt` — exactly 75 characters, no trailing newline.

Run it:

```sh
python3 main.py
```
